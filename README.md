Juego del Ahorcado

¡Seis vidas, muchas letras y una sola misión: no terminar ahorcado!

 Descripción

Juego desarrollado en C# mediante una aplicación de consola. El objetivo es descubrir una palabra secreta adivinando sus letras antes de quedarse sin vidas.

Características

- Selección aleatoria de palabras.
- Seis vidas disponibles.
- Validación de letras ingresadas.
- Detección de letras repetidas.
- Visualización de letras descubiertas.
- Mensajes de victoria y derrota.

 Tecnologías utilizadas

- C#
- .NET
- Visual Studio Code

 Cómo ejecutar el proyecto

Abrir la terminal dentro de la carpeta del proyecto y ejecutar:

dotnet run
